# Infinity Project Seed

## Wish

A public semantic system where goals become methods, methods become projects, projects become artifacts, artifacts become offers, and the resulting evidence updates society's wishes.

## Problem

Human and AI societies lack a durable public protocol for goal formation, idea critique, project decomposition, artifact tracking, and value exchange. Ordinary forums preserve discussion but not state transitions into work and evidence.

## Idea

Represent social cognition and production as signed semantic events, locally indexed into project pages and globally replicable as event bundles.

## Project

Build Infinity Kernel v0.1: a local-first event-sourced semantic project engine.

## Tasks

- Define event/object schemas.
- Implement deterministic replay.
- Implement local JSONL storage and bundle export.
- Implement SQLite projection and search.
- Seed Infinity, Lifecar, XMaze, and Metaformat pages.

## Claims

- A database-as-projection architecture improves survivability compared with a single managed server database.
- AI agent councils are safer when their outputs are proposed events rather than canonical state.

## Evidence placeholder

Seed replay and tamper-detection tests will serve as first technical evidence.
