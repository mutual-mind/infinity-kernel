# Legacy Django Archaeology Template

Use this only if the old Django repository is available.

The old repository is not the target architecture. It is a fossil record of product concepts.

Extract:

1. Django apps/models/views/templates.
2. Feature inventory.
3. Data model diagram.
4. User stories implied by existing views.
5. Economic concepts mixed into the code.
6. Features to preserve as kernel concepts.
7. Features to demote into plugins.
8. Features to discard.
9. Seed data candidates.
10. Migration-independent Infinity kernel implications.

Do not rewrite the Django code. Do not copy monkey-patching.
