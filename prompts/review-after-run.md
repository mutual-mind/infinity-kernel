# Review after unattended Codex run

Review the current working tree.

Produce:

1. concise summary of implemented packages and commands;
2. list of passing/failing checks;
3. architecture violations, especially kernel dependencies on UI/database/storage;
4. missing acceptance criteria from `docs/ACCEPTANCE_CRITERIA.md`;
5. top 10 fixes in priority order;
6. whether this repository is ready for Goal 002.

Do not implement fixes unless they are tiny and obviously safe. Prefer review.
